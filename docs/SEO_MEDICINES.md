# SEO карточек лекарств (24.10.2026)

SEO title, SEO description и keywords карточки лекарства собирает код, а не модель:
`backend/apps/ai/services/medicine_seo.py`, вызов — `ContentGenerator._build_medicine_seo`.
Правила взяты из SEO-плана медикаментов (`SEO_HANDOFF.md`, кластеры Вордстата и подсказок Google, 23.10.2026).
Страницы категорий и подборок — PR #165 (миграция `catalog/0222_medicine_landing_seo_texts`).

## Почему кодом

В пилоте 23.10.2026 модель теряла действующее вещество в SEO title у 32 лекарств из 50.
Бренда кириллицей у неё не было вовсе, а правила плана промптом не держатся: не писать «без рецепта»,
отмечать холодовую цепь, не продвигать препараты строгого учёта. Код собирает SEO из уже
проверенных частей, и каждое правило закреплено тестом.

## Из чего собирается

| часть | откуда |
|---|---|
| бренд латиницей | начало названия кодом (`title_brand`), с числом после бренда («CAPD 4 STAY SAFE»); производитель (`Product.brand`) в SEO не пишется |
| бренд кириллицей | словарь брендов: память переводов, namespace `medicine_brand` («MAJEZIK» → «Мажезик»; ключ — бренд абзацев `paragraph_brand`, для «PHYSIONEAL 40» берётся «Физионеал» + « 40»). Транслитерация — по латинскому чтению упаковки, как ищут покупатели («ENCEF» → «Энцеф», не «Энджеф»). Если бренд и есть вещество («IBUPROFEN 400 MG»), кириллицей пишется МНН |
| действующее вещество | то же, что в скобках названия (`title_inn`, словарь `medicine_inn`) |
| дозировка и форма | части названия кодом после бренда |
| рецепт | перевод типа рецепта (`PRESCRIPTION_TYPES`) → `prescription_kind`: rx / otc / controlled |
| холодовая цепь | условия хранения из источника: «2–8 °C» или «buzdolabında saklayınız» (`needs_cold_chain`) |

## Правила

- **SEO title** (до 70 символов): «Мажезик (MAJEZIK, флурбипрофен) 100 мг, таблетки из Турции».
  - Перебираются варианты от полного к короткому, берётся первый, что помещается: с формой и « — инструкция, цена»; с формой; только с дозировкой; без вещества; без «из Турции» (бренд кириллицей важнее); бренд только латиницей («POLIFLEKS 1/3 POLIDEKS, раствор для внутривенных инфузий из Турции»).
  - Если не помещается ничего, заголовок режется по слову и не кончается предлогом («…, раствор для»).
  - EN: «MAJEZIK (flurbiprofen) 100 mg, film-coated tablets from Turkey».
- **SEO description** (до 160 символов): начало «бренд (вещество) доза, форма из Турции.», затем по важности:
  1. «Отпускается по рецепту.»;
  2. «Хранение и перевозка при 2–8 °C.»;
  3. «Инструкция на русском.»;
  4. «Заявка менеджеру, доставка 7–21 рабочий день.»;
  5. действующее вещество, если его нет в начале.

  Предложение, которое не помещается, пропускается.
- **Keywords**: бренд латиницей и кириллицей, вещество, форма, «… из Турции», «… инструкция».
- **Не пишется никогда**: «без рецепта» (у безрецептурных о рецепте ничего), обещания лечения и продажи.
- **Препараты строгого учёта** (красный, зелёный, оранжевый, фиолетовый рецепт: фентанил, прегабалин и т. п.):
  - нет «из Турции», цены, заявки и доставки;
  - есть пометка «Препарат строгого учёта, отпускается по специальному рецепту».

  Полный запрет продвижения и пометка в админке — техдолг TD-023.

Модель пишет короткое описание карточки и SEO-черновик по тем же правилам. Если код собрал название,
её SEO заменяется кодом. Если не собрал (незнакомое слово в исходнике: растворы для диализа, пастилки,
пластыри), остаётся SEO модели. Если модель SEO не вернула, код берёт её название и описание
(`_apply_medicine_code_fields`). В пилоте 24.10.2026 так было у 10 из 50, и лог падал.

## Как менять надёжно

1. Тексты и порядок частей — константа `_TEXTS` в `medicine_seo.py`, тесты — `apps/ai/tests/test_medicine_seo.py`
   и сквозная обработка MAJEZIK в `test_medicine_code_pipeline.py`. Изменение — PR с тестом, CI, релиз.
   Промпт модели для SEO лекарств править не нужно.
2. Бренд кириллицей или МНН поправить в админке: «AI → Память переводов», namespace `medicine_brand` или
   `medicine_inn`. Правка бренда действует со следующей обработки товара. Правка МНН сразу
   обновляет поле «Действующее вещество» у обработанных товаров (сигнал `propagate_medicine_inn_edit`),
   а название и SEO — со следующей обработки.
3. Перед массовой обработкой — пилот на 50 лекарств с просмотром карточек
   (порядок — `docs/MEDICINE_TRANSLATION_KNOWLEDGE_BASE.md`).

## Не сделано

- SEO у уже опубликованных лекарств (≈ 200) пересчитывается только при переобработке. Пересчёт без
  модели можно сделать отдельной командой.
- Страницы-группы препарата (бренд и все формы), блог и микроразметка FAQ — пункты 3–6 SEO-плана.
- noindex и запрет продвижения препаратов, запрещённых к ввозу в РФ и СНГ, — TD-023.
