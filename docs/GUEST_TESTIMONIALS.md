# Отзывы о сервисе без входа в аккаунт

С 26.11.2026 отзыв на странице `/testimonials` можно оставить без регистрации: заявки на сайте
оформляются без аккаунта, и ссылка `/testimonials?action=add` из готового сообщения «Просьба
об отзыве» ([ORDER_PROCESSING.md](ORDER_PROCESSING.md)) ведёт гостя прямо к форме.

## Как это работает

- **Форма гостя**: имя (до 100 знаков), оценка, текст (до 3000 знаков). Фото и видео гостю
  не предлагаются и сервером не сохраняются: файл попадает в хранилище сразу при отправке,
  до проверки, а гостя нельзя ограничить по аккаунту. Вошедший в аккаунт пользователь видит
  прежнюю форму с фото и видео; подпись берётся из его профиля.
- **Показ только после проверки**: отзыв создаётся с выключенной галочкой «Активен»
  (`Testimonial.is_active = False`) — так было и раньше для вошедших. Публичные адреса
  (`/api/feedback/testimonials/`, `/api/feedback/reviews-feed/`) отдают только активные.
- **После отправки** посетитель видит сообщение «Отзыв отправлен! … будет опубликован после
  проверки».
- **Уведомление владельцу**: о каждом новом отзыве о сервисе (гостевом и от вошедшего) в чат
  `TELEGRAM_CHAT_ID` приходит сообщение со ссылкой на отзыв в админке
  (`feedback.tasks.notify_admin_testimonial`).

## Отметка «Покупатель» (личная ссылка из заявки)

- **Откуда ссылка**: подстановка `{ссылка на отзывы}` в готовом сообщении «Просьба об отзыве»
  (кнопка «⭐ Попросить отзыв» под заявкой в Telegram) даёт адрес
  `/testimonials?action=add&k=<ключ>`. Ключ — случайная строка (`secrets.token_urlsafe(16)`),
  хранится в заявке (`Order.review_token`) и заводится при первой сборке такого сообщения;
  повторные нажатия дают ту же ссылку. Номера заявки, имени и телефона в адресе нет.
- **Что даёт**: отзыв, отправленный по такой ссылке (гостем или вошедшим), связывается с
  заявкой (`Testimonial.order`), а в публичном API получает `is_buyer: true`. На витрине рядом
  с именем автора — зелёная отметка «Покупатель» (EN — «Verified buyer»): страница отзывов,
  страница одного отзыва, блок отзывов на главной.
- **Проверка перед показом** остаётся: отзыв с отметкой тоже создаётся неактивным.
- **Один отзыв с отметкой на заявку**: повторный по той же ссылке, а также отзыв с неверным
  ключом или без ключа принимается как обычный, без отметки и без ошибки для человека.
- **Наружу не отдаётся** ничего о заявке: ни номер, ни товары, ни суммы — только признак
  `is_buyer`.
- **Админка**: в списке отзывов столбец «Покупатель (заявка)» со ссылкой на заявку и фильтр
  «Отметка „Покупатель“»; в уведомлении владельцу в Telegram — «покупатель, заявка №…».
  Поле в карточке отзыва только для чтения: вручную отметку не поставить и не снять.

## Защита от спама

- **Поле-ловушка** `website`: в форме скрыто, человек его не заполняет. Если оно пришло
  заполненным, сервер отвечает «принято», но ничего не сохраняет и не уведомляет.
- **Частота**: 2 отзыва в час и 5 в сутки (`feedback/throttles.py`). Вошедшего считаем по
  аккаунту, гостя — по адресу, который подставил nginx (`TrustedIdentMixin`), а не по
  присланному заголовку `X-Forwarded-For`. Сверх лимита — ответ 429 и сообщение «Попробуйте
  позже».
- **Длина текста** — до 3000 знаков для всех (`TESTIMONIAL_TEXT_MAX_LENGTH`).
- Капчи и сторонних сервисов нет.

## Админка

Блок «Отзывы и вопросы»:

- **«💬 Отзывы — Отзывы»** — фильтр справа «Активен: Нет» показывает ждущие проверки. У
  гостевого отзыва столбец «Пользователь» пустой. Опубликовать: отметить отзывы →
  «Действие» → «Опубликовать выбранные отзывы» → «Выполнить» (или поставить галочку
  «Активен» в списке и нажать «Сохранить»). Отклонить — оставить неактивным или удалить.
  Обратное действие — «Снять выбранные отзывы с публикации».
- **«💬 Отзывы — Настройки»** — одна запись с галочкой «Принимать отзывы без входа в
  аккаунт» (`TestimonialSectionSettings.allow_guest_testimonials`, по умолчанию включена).
  Если выключить, сервер отвечает гостю 401, а страница просит войти и ведёт на вход.
