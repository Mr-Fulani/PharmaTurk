# Главная админки: плитки частых разделов и единый вид кнопок

Дата: 20.11.2026. Код: `backend/config/admin_tiles.py` (`home_tiles`),
`MudarobaAdminSite.index` (`backend/config/admin.py`), шаблоны
`backend/templates/admin/_home_tiles.html`, `mudaroba_index.html`; стили —
`backend/templates/admin/_mudaroba_styles.html` (подключены в `base_site.html` на всех
страницах админки). Тесты — `config/tests/test_admin_home_tiles.py`.

## Плитки

Вверху главной страницы админки — сетка плиток, под ней поле «Проверить лекарство» и
прежний полный список разделов. На телефоне плитки идут по две в ряд, на планшете по
три–четыре, на широком экране по шесть.

| Плитка | Число | Куда ведёт |
|---|---|---|
| Заявки | не закрытые (всё, что не «завершена» и не «отменена»); строкой ниже — новых за сутки | список заявок `?processing=open` |
| Найдём товар | не закрытые заявки типа «🔎 Найти товар» (с 22.11.2026 они ведутся в «Заказах», [ORDER_PROCESSING.md](ORDER_PROCESSING.md)) | список заявок `?kind__exact=sourcing&processing=open` |
| Пользователи | всего; строкой ниже — зарегистрировались за 7 дней | список, новые сверху |
| Списки заявки (корзины) | списки с товарами, которые меняли за сутки; строкой ниже — за 7 дней | список, последние изменённые сверху (колонка «Дата обновления») |
| Цены товаров | — | «Цены товаров» |
| Настройки цен и наценок | — | «Глобальные настройки валют» |
| Проверка лекарства | — | поиск по названию или штрихкоду ([DRUG_CHECK.md](DRUG_CHECK.md)) |
| Лекарства, БАДы | — | списки каталога |
| Ночная сверка наличия | источников на паузе (предохранитель остановил сверку) | [NIGHTLY_STOCK_CHECK.md](NIGHTLY_STOCK_CHECK.md) |
| Неактуальные товары | «Нет у продавца» — ждут решения | список с этим статусом ([STALE_PRODUCTS.md](STALE_PRODUCTS.md)) |

Правила:

- Плитка видна только тому, кому разрешён просмотр раздела (право модели из `TILES`;
  «Проверка лекарства» — право на лекарства). Без прав блока плиток нет.
- Числа считаются на сервере при открытии страницы: по одному `COUNT` на число, без
  фоновых задач и JavaScript. Ошибка счётчика (`_count`) — плитка без числа, запись
  `admin_home_tile_count_failed` в журнале; ошибка сборки плитки — плитка пропускается
  (`admin_home_tile_failed`). Главная не падает.
- Новая плитка — строка в `TILES`: приложение, модель (по ней проверяется право и строится
  адрес списка) и функция, которая возвращает `icon`, `title`, `url` и по желанию `value` +
  `value_label`, `extra` + `extra_label`, `note`.
- Номер колонки сортировки (`?o=-N`) берётся из `list_display` админки (`_column`): колонку
  `date_joined` у пользователей и `updated_at` у корзин из списка не убирать.

## Кнопки-ссылки

Один вид кнопок на всю админку — класс `mud-btn` (функция `admin_button` в
`apps/catalog/admin_links.py`): рамка, значок, высота не меньше 44 px; компактный вариант
для таблиц — `mud-btn--small`. Цвета — переменные темы админки, работают светлая и тёмная.

- Полоса кнопок карточки (`templates/admin/change_form.html`, `ul.mud-btn-bar`) стоит под
  заголовком на всех страницах изменения записи; на телефоне кнопки идут в столбик на всю
  ширину. Что в ней у товара — [ADMIN_PRODUCT_LINKS.md](ADMIN_PRODUCT_LINKS.md).
- В заявке у каждой позиции — «Карточка в админке», «На сайте», «У продавца»
  (`OrderItemLinksMixin.item_links`, ряд `div.mud-btn-row`; на телефоне — в столбик).

Админка не получает CSP сайта ([SECURITY_CSP.md](SECURITY_CSP.md)), но новые блоки сделаны
без JavaScript и без атрибутов `style=`.
