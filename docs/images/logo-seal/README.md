# Логотип сайта — сургучная печать с пальмой

С 27.11.2026 знак Mudaroba — красная сургучная печать с золотой пальмой (картинка владельца).
Прежний знак — красный квадрат с белой линией пульса; во вкладке браузера до этого стояла
зелёная пальма. Надпись «MUDAROBA™» рядом со знаком в шапке не менялась.

Исходник — `logo-source.webp`: 1254×1254, печать на сплошном чёрном фоне, прозрачности нет,
вектора нет. Все файлы ниже, кроме картинок «О нас», собирает `build_logo.py`: вырезает печать
с чёрного фона (прозрачность — по яркости, у края — чистый цвет сургуча, поэтому чёрной каймы
нет ни на светлом, ни на тёмном фоне) и уменьшает с учётом гаммы и прозрачности, мелкие
размеры — с лёгкой резкостью.

## Где логотипа нет

- Подвал сайта — только надпись «Mudaroba™».
- Письма покупателю и менеджерам, PDF-чек: в шапке надпись «Mudaroba» и золотой полумесяц
  со звездой (украшение, не знак сайта). PDF собирается без внешних файлов.
- Сообщения бота и посты Telegram-канала (фото товаров), YML-фид ВК, `llms.txt`.
- Манифеста (`manifest.webmanifest`) у сайта нет.

## Значок вкладки и кэш браузера

Браузер хранит значок вкладки отдельно от кэша страниц и по прежнему адресу сам его не
обновляет (Chrome — только после Ctrl+F5). Поэтому у ссылок на значки в `pages/_app.tsx`
стоит `?v=seal`: вернувшийся посетитель получает новый значок без чистки кэша. Сменились файлы
значка — поменять `?v=`. В админке ссылка без `?v=`: там значок обновится после Ctrl+F5
(на Mac — Cmd+Shift+R).

Поисковики меняют значок в выдаче сами: Яндекс — до нескольких недель, Google — от нескольких
дней до недель.

## Пересборка

```bash
python3 docs/images/logo-seal/build_logo.py ~/Desktop/mudaroba-logo-kit
```

Нужны Pillow, numpy, scipy и `cwebp` (`brew install webp`). Скрипт перезаписывает файлы из
таблицы, кроме превью и картинок «О нас»; превью после этого пересобрать по
[../og-default/README.md](../og-default/README.md) (они берут `logo-512.png`). Необязательный
аргумент — папка для файлов внешних мест (в репозиторий не идут): прозрачные PNG 512 и 1024 и
квадратные аватарки 512 и 1024 на чёрном, кремовом и белом фоне — печать занимает 80 %
стороны и целиком помещается в круг, которым соцсети обрезают аватарку.

## Как вернуть прежний знак

Отменить коммит замены (`git revert`) и выкатить сайт: прежние файлы остаются в истории Git.
