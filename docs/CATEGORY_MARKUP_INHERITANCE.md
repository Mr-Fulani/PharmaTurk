# Наследование товарной наценки

Приоритет расчёта: положительная наценка бренда, затем самой категории,
затем ближайшего родителя с положительной наценкой, затем глобальная настройка.
Проценты уровней не складываются. Ноль сохраняет прежнее значение «не задано»;
он не отключает наследование. Валютная наценка рассчитывается отдельно.

Общий расчёт используется карточками, актуализацией цены источника и корзиной.
Сохранённые цены оформленных заказов и их чеков не пересчитываются.
API продолжает возвращать источник `category` для наценки из дерева категорий.

Изменение не требует миграций, обновления товаров или массового сохранения
процентов в подкатегориях. При изменении наценки родителя новые запросы используют
актуальное значение. Для карточек загружаются связи двух родителей заранее;
произвольная глубина поддерживается расчётом, циклы не приводят к зависанию.

Проверки покрывают приоритеты, вложенные уровни, циклы, отсутствие категории,
переопределение подкатегорией и брендом, отсутствие повторных запросов на
предзагруженных связях, согласованность карточки/корзины и сохранение цен заказов.
Автокатегоризация медикаментов и её включение не входят в этот релиз.
