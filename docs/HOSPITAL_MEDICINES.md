# Больничные препараты: справочная отметка

Обновлено: 2026-11-19.

## Что это

Больничный препарат — лекарство, которое в Турции применяют в основном в больницах: растворы для
капельниц и кровезаменители, растворы для диализа, кожные пробы и аллергены для диагностики,
радиофармпрепараты, а также препараты, у которых на IlacFiyati нет розничной цены, только госцена
(например, APROKAM, OLIMEL, PERIOLIMEL).

Такие препараты **не скрываются** — сайт работает как справочник лекарств (решение владельца
13.11.2026). Карточка открыта, есть в разделе, в поиске и в карте сайта.

**Цена — решение владельца 19.11.2026: цену не скрываем.** Справочник даёт исчерпывающую информацию
о препарате, включая цену.

- **Есть цена (больше нуля)** — препарат ведёт себя как обычное лекарство: цена в API, на карточке и
  странице, в поиске, избранном, аналогах, в «Списке заявки» и в сумме, в сообщении менеджеру.
  Отметка «Больничный препарат» — только подпись рядом с ценой.
- **Цены нет** — «Больничный препарат · цена по запросу», в сумму заявки не входит; цену, наличие и
  возможность доставки называет менеджер.

С 13.11 по 19.11.2026 (PR #403) цена больничных скрывалась у всех, даже когда она была в базе.

История: 26.10.2026 1 234 больничных препарата были скрыты (`is_active=False`, отбор по шаблонам в
названии, список `reports/hospital_to_hide_2026-10-26.csv`, бэкап на сервере
`~/backups/hospital_hide_backup_20261026.json`). Из них у 1 107 была розничная цена, у 127 — нет.
После выката признака их возвращают на витрину с отметкой «больничный».

## Признак

`MedicineProduct.is_hospital` (флажок «Больничный препарат» в карточке лекарства в админке, фильтр
в списке лекарств). Ставится вручную, командой сверки или парсером IlacFiyati — только у нового
лекарства, по правилу ниже. У лекарства, которое уже есть в базе, парсер флажок не ставит и не
снимает: ручная отметка главнее. Цена обновляется парсером как обычно и показывается на сайте.

Код: `backend/apps/catalog/hospital_medicines.py` (показ), `backend/apps/catalog/hospital_rule.py`
(правило).

## Правило «похоже на больничный» (TD-047, 19.11.2026)

Одна функция `hospital_medicine_group(название в источнике, ATC)` — возвращает группу или пусто.
Собрана по двум прежним отборам: 26.10.2026 (по названию) и 13.11.2026 (по коду ATC).

| Группа | По коду ATC | По названию (турецкому) |
|---|---|---|
| Диализ и гемофильтрация | B05D, B05Z | `PERITON… DIYALIZ/DIALIZ`, `HEMODIYALIZ`, `HEMOFILTRASYON` |
| Радиофармпрепараты | V09, V10 | `RADYOFARMASOTIK`, `RADYONUKLID`, `JENERATOR`, единицы `MBQ`/`GBQ` |
| Кожные пробы и аллергены | V01AA, кроме таблеток | `PRICK TEST` (и опечатка `PRIK TEST`) |
| Диагностические средства | V04C | — |
| Растворы для капельниц и питания | B05A, B05B, B05C, B05X — если в названии есть признак введения в вену (инфузия, инъекция, ампула, флакон, пакет, эмульсия) и нет формы для приёма дома | без кода ATC: `SETLI`/`SETSIZ` (тара с системой для капельницы / без неё) или раствор-носитель (декстроза, натрия хлорид, Рингер, маннитол, аминокислоты, жировая эмульсия) вместе со словом «инфузия»/«ирригация» либо объёмом от 100 мл |

Правило осторожное — лучше не отметить, чем отметить аптечное лекарство. Не отмечаются:

- лекарство с другим кодом ATC, даже если в названии «для инфузий» (антибиотики, онкология, наркоз,
  парацетамол для капельниц) — это шире решения 26.10;
- альбумин (B05AA01) — решение владельца не принято;
- масла и смеси лечебного питания, препараты для приёма внутрь с кодом B05 (MCT OIL, MONOGEN,
  аргинин в питьевых ампулах);
- ампулы без кода ATC (по одному названию);
- лекарство без розничной цены само по себе: таких ~2 300, в основном импортные под пациента —
  для них верна обычная «Цена по запросу».

«Розница 0 при госцене» в правило не вошла: парсер госцену не сохраняет, в сохранённых примерах
страниц IlacFiyati её нет, а без неё «нет цены» больничным не делает (см. выше). Три таких препарата
(APROKAM, OLIMEL, PERIOLIMEL) отмечены вручную.

Проверка на прежних списках: из 1 234 названий отбора 26.10 правило по одному названию находит
1 189 (остальные 45 — ампулы калия хлорида и физраствора и аллергены ALLERMUNE, которые находятся
по коду ATC, плюс два случайных попадания старого отбора: глазные капли COREDEM и иммуноглобулин
HYPER-HEP B); из 64 отмеченных 13.11 — все 64; из
2 287 лекарств без цены, не отмеченных 13.11, — два (жировые эмульсии для капельниц OLIVIA и
REXOMEGA-3).

### Где применяется

- **Парсер IlacFiyati, новое лекарство** (`ScraperIntegrationService._flag_new_hospital_medicine`):
  при создании карточки ставит `is_hospital=True`, если правило сработало. Заглушка аналога
  оценивается только по названию (её ATC унаследован от другого препарата) и ещё раз — когда
  получает собственную карточку. При обычном обновлении правило не вызывается.
- **Сверка** — команда `check_hospital_medicines` (ниже).

### Сверка `check_hospital_medicines`

Показывает показанные на сайте лекарства (без заглушек и скрываемых вторых страниц), у которых
отметка и правило расходятся: «подходит под правило, не отмечен» и «отмечен, под правило не
подходит» (вторые — ручные отметки, команда их никогда не снимает). По умолчанию только показ.

```bash
manage.py check_hospital_medicines                         # показ: счётчики и по 20 примеров
manage.py check_hospital_medicines --csv /tmp/hospital.csv # показ + полный список в CSV
manage.py check_hospital_medicines --group Диализ          # только группы с этим текстом в названии
manage.py check_hospital_medicines --apply --backup /backups/hospital.json
```

`--apply` отмечает только неотмеченные (можно вместе с `--group`), пишет бэкап «до» (файл не
перезаписывается) и пересчитывает порядок в разделе (от самой отметки он с 19.11.2026 не зависит).
Цены, наличие и показ не меняются.
Откат: `MedicineProduct` с `id` из бэкапа — `is_hospital=False`.

## Где и как показывается

| Место | С ценой | Без цены |
|---|---|---|
| Страница препарата | обычная цена, под ней подпись «Больничный препарат · применяется в основном в больницах. Наличие и возможность доставки уточнит менеджер.»; кнопка «Узнать актуальную цену» есть | плашка «Больничный препарат · цена по запросу» и пояснение; кнопки «Узнать актуальную цену» нет |
| Карточка в разделе, поиске, избранном, на странице бренда, в аналогах | обычная цена и мелкая подпись «Больничный препарат» | «Больничный препарат · цена по запросу» вместо цены |
| API товара (`/medicines/products/…`, `/products/…`, `view=card`, аналоги) | цены как у обычного лекарства, `is_hospital: true` | цены пустые (их нет в базе), `is_hospital: true` |
| Проверка цены `/medicines/products/<slug>/market-check` | работает как у обычного лекарства | 404 `hospital_price_on_request` |
| «Список заявки» и оформление | обычная позиция с ценой, входит в сумму | «Больничный препарат · цена по запросу», «Не включено в итог» (цена позиции 0) |
| Заявка менеджеру (Telegram) | обычная строка с ценой, входит в сумму | строка «Цена по запросу (в сумму не вошли): …» |
| Чек (письмо и PDF) | цена | «по запросу» вместо «0.00» |
| Порядок в разделе | как у товара с ценой | как у товара без цены — после товаров с ценой |
| Справочный блок лекарств на главной (`/products/medicine-reference`; в «Хитах продаж» лекарств нет вовсе с 19.11.2026), персональные рекомендации | показываются как обычные лекарства | не показываются |
| Проверка лекарства в админке ([DRUG_CHECK.md](DRUG_CHECK.md)) | «Принять цену IlacFiyati» работает как у обычного лекарства | то же: принятая цена сразу появится на сайте |

Одинаково в обоих случаях: «В заявку» и «Как заказать» — как у любого лекарства; метка «Ввоз
ограничен» — как обычно; разметка для поисковиков (JSON-LD) без Offer (у лекарств его нет вообще);
в YML-фид ВК / Яндекса и в Merchant Center не попадают (лекарства туда не идут); в карте сайта есть.

Поле `product_is_hospital` у позиции «Списка заявки» стоит у любого больничного; подпись
«Больничный препарат · цена по запросу» появляется только вместе с `price_on_request`.
«Цена по запросу» в «Списке заявки» показывается и у других товаров без цены (раньше там было
«0 ₽»): поле позиции `price_on_request`.

Позиции, добавленные в «Список заявки» до 19.11.2026, сохранены с ценой 0; при показе списка и при
оформлении цена берётся свежая, так что в заявку они попадут с ценой.

## Как отметить или снять

- Один препарат: админка → Медикаменты → карточка → «Больничный препарат».
- Много по правилу: `check_hospital_medicines` — сначала показ и CSV, затем `--apply --backup`.
- Много по списку: разовая запись на проде по списку id, с бэкапом (как 13.11.2026), затем пересчёт порядка в
  разделе — функция `recompute_sort_ranks(MedicineProduct)` из `apps.catalog.services.catalog_sort_rank`
  в `manage.py shell`. На порядок отметка больше не влияет (с 19.11.2026 он зависит только от
  наличия цены), пересчёт нужен, только если вместе с отметкой менялись цена или наличие.
