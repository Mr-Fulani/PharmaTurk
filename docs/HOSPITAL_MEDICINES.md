# Больничные препараты: «цена по запросу»

Обновлено: 2026-11-13.

## Что это

Больничный препарат — лекарство, которое в Турции применяют в основном в больницах: растворы для
капельниц и кровезаменители, растворы для диализа, кожные пробы и аллергены для диагностики,
радиофармпрепараты, а также препараты, у которых на IlacFiyati нет розничной цены, только госцена
(например, APROKAM, OLIMEL, PERIOLIMEL).

Решение владельца 13.11.2026: такие препараты **не скрываются** — сайт работает и как справочник
лекарств. Карточка открыта, есть в разделе, в поиске и в карте сайта, но цена не показывается:
вместо неё «Больничный препарат · цена по запросу». Цену, наличие и возможность доставки называет
менеджер по заявке. То же решение — для всех таких препаратов, даже если у IlacFiyati есть розничная
цена: тяжёлые растворы дорого везти, цена с сайта ввела бы покупателя в заблуждение.

История: 26.10.2026 1 234 больничных препарата были скрыты (`is_active=False`, отбор по шаблонам в
названии, список `reports/hospital_to_hide_2026-10-26.csv`, бэкап на сервере
`~/backups/hospital_hide_backup_20261026.json`). Из них у 1 107 была розничная цена, у 127 — нет.
После выката признака их возвращают на витрину с отметкой «больничный».

## Признак

`MedicineProduct.is_hospital` (флажок «Больничный препарат» в карточке лекарства в админке, фильтр
в списке лекарств). Ставится вручную или разовой записью на проде; парсер его не меняет и не ставит
сам (см. TD-047 в [TECH_DEBT.md](TECH_DEBT.md)). Цена в базе остаётся и обновляется парсером как
обычно — она просто не выходит на сайт.

Код: `backend/apps/catalog/hospital_medicines.py`.

## Где и как показывается

| Место | Что видно |
|---|---|
| Страница препарата | плашка «Больничный препарат · цена по запросу» и пояснение; кнопки «Узнать актуальную цену» нет; «В заявку» и «Как заказать» как обычно; метка «Ввоз ограничен» — как обычно |
| Карточка в разделе, поиске, избранном, на странице бренда, в аналогах | «Больничный препарат · цена по запросу» вместо цены |
| API товара (`/medicines/products/…`, `/products/…`, `view=card`, аналоги) | все поля цены пустые (`price`, `price_formatted`, `old_price…`, цены в валютах), `is_hospital: true` |
| Проверка цены `/medicines/products/<slug>/market-check` | 404 `hospital_price_on_request` |
| «Список заявки» и оформление | позиция с надписью «Больничный препарат · цена по запросу», «Не включено в итог»; в сумму не входит (цена позиции 0) |
| Заявка менеджеру (Telegram) | строка «Цена по запросу (в сумму не вошли): …» с названиями таких позиций |
| Чек (письмо и PDF) | «по запросу» вместо «0.00» |
| Порядок в разделе | как у товара без цены — после товаров с ценой |
| Хиты (`/products/featured`), блок «Популярное» на главной, похожие товары, персональные рекомендации | не показываются |
| Разметка для поисковиков (JSON-LD) | без Offer (у лекарств его нет вообще) |
| YML-фид ВК / Яндекса | не попадает (лекарства в фид не идут) |
| Карта сайта | есть (как любое активное лекарство) |

«Цена по запросу» в «Списке заявки» показывается и у других товаров без цены (раньше там было
«0 ₽»): поле позиции `price_on_request`.

## Как отметить или снять

- Один препарат: админка → Медикаменты → карточка → «Больничный препарат».
- Много: разовая запись на проде по списку id, с бэкапом (как 13.11.2026), затем пересчёт порядка в
  разделе — функция `recompute_sort_ranks(MedicineProduct)` из `apps.catalog.services.catalog_sort_rank`
  в `manage.py shell` (иначе препарат до ночной задачи `catalog.recompute_sort_ranks` стоит среди
  товаров с ценой).
