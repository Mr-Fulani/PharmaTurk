## Сознательно не сделано

  RUB, на странице RUB (564.63 / «565 RUB» — округление вверх при показе) — расхождения из
  аудита (TRY) больше нет.
- **Задача 2, IndexNow для категорий, брендов, препаратов и разовая отправка всего sitemap.**
  По `INDEXNOW.md` они сознательно идут только через sitemap; протокол просит слать только
  изменённые адреса, массовая отправка всех ~50 тыс. адресов не рекомендуется. Если нужно —
  отдельная задача.
- **Задача 7 для товаров без своей копии фото** (например, «Мирена»: фото с
  imgcdn.mckesson.com). `proxy-image` пускает только R2 и Instagram, а менять `/api/*` ТЗ
  запрещает. Вариант — копировать главное фото таких товаров в R2 (отдельная задача).
- **Задача 9, lastmod товаров** = `updated_at`, а он меняется и при утреннем пересчёте цен по
  курсу. Исправление — отдельный отпечаток содержимого, как в IndexNow (бэкенд). У индекса
  sitemap lastmod — дата сборки.
