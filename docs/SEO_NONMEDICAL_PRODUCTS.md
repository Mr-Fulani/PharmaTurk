# SEO карточек обуви, одежды и аксессуаров (правила без LLM)

Обновлено: 05.11.2026. Код: `backend/apps/ai/services/rules/` (`vocab.py` — словари,
`facts.py` — разбор турецкого названия, `text.py` — название, title, description,
ключевые слова). Тесты: `backend/apps/ai/tests/test_rule_content.py`.

Работает для типов `clothing`, `shoes`, `underwear`, `headwear`, `islamic_clothing`,
`accessories`, `perfumery`, `furniture` (`RULE_PRODUCT_TYPES`). Спорттовары и посуда
(`sports`, `tableware`) пока идут через LLM целиком.

Исследование спроса, на котором основаны слова ниже, — `reports/superstep-seo-core-2026-11-05.md`.

## Название

`<пол> <тип> <бренд> <модель> <до 2 описаний>, <цвет>`:
«Мужские кроссовки Nike Air Force 1 '07, белые», «Женские угги UGG Classic Ultra Mini».

- **Тип** — из названия (`KINDS`), иначе из раздела (`CATEGORY_KINDS`): «Şapka» в разделе
  «Бейсболки» — «бейсболка», а не «головной убор».
- **Бренд + тип** (`BRAND_KINDS`): UGG + «Bot» — «угги» (так их ищут).
- **Модель** — латинские слова между брендом и турецкими словами. Номер сразу за брендом
  (`New Balance 9060`, `2002`) — модель; у LC Waikiki и после типа («Tişört 4480») — артикул.
  Коды через дефис с двумя и меньше цифрами (`Sk8-Hi`, `XT-6`) — модель; `J5SM-TST7325`,
  `PC-7315` — артикулы.
- Слово бренда в модели не повторяется, кроме имён вроде «New York» у New Era
  (`BRAND_WORD_PHRASES`).
- Непереведённое турецкое слово → название пишет LLM (`facts.untranslated`). Новое слово —
  в словарь `vocab.py`, не в код.

## Title и description

- Title (до 70 знаков): «<название> — купить оригинал из Турции», при нехватке места —
  без цвета, потом «— оригинал из Турции», потом «из Турции».
  «Оригинал» — частое уточнение в запросах о брендах и моделях («nike air force 1 белые
  оригинал», «угги ugg оригинал»).
- Description (до 160): «<название>. [Модель унисекс — для мужчин и женщин.] Оригинальный
  товар из Турции с доставкой. <первое предложение описания>». Фраза про унисекс — потому что
  ищут «кроссовки мужские» и «кроссовки женские», а не «унисекс».
- Ключевые слова (до 10): название без цвета, тип, «мужские …/женские …» (для унисекс — обе),
  «<тип> <бренд> <модель>», «<тип> <бренд кириллицей>» (`BRAND_RU`: «кроссовки адидас»),
  «<бренд> <модель> оригинал», «<тип> из Турции», бренд.
- Бренд кириллицей — только в ключевых словах; в названии и title — как у производителя.

## Адрес товара (slug)

Ставится один раз при создании товара (`CatalogNormalizer.normalize_product`) и потом сам
не меняется. Обычно — исходное название транслитом + `external_id`
(`adidas-samba-og-unisex-beyaz-spor-ayakkab-superstep-B75806`).

У источников из `RU_TITLE_SLUG_SOURCES` (сейчас `superstep`, 05.11.2026) — русское название
по правилам выше без цвета, транслитом, и код модели без имени источника:
`krossovki-uniseks-adidas-samba-og-b75806`, `zhenskie-uggi-ugg-classic-ultra-mini-1116109`.
Цвета в адресе нет: в карточке несколько цветов. Правила не назвали товар (спорттовары,
посуда, непереведённое слово) — «бренд модель» латиницей. Такой адрес уже занят (тот же
артикул у другого источника) — прежний слаг с префиксом источника.

Уже созданные товары не меняются. Смена их адреса — отдельная запись на прод с
301-переадресацией (`ProductSlugHistory`), только с согласия владельца.

## Что меняется для уже обработанных товаров

Ничего само не меняется: правила срабатывают при новом AI-прогоне товара. Массовый прогон —
только после пилота и с согласия владельца.
