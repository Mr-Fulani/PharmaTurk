## 3. Страница препарата: `/drugs/<slug>`

Один бренд и все его формы и дозировки на одной индексируемой странице (`/en/drugs/<slug>` —
английская версия). Карточки форм остаются как были, с них ведёт ссылка «Все формы и дозировки:
Мажезик (MAJEZIK) →».

| Блок | Откуда |
|---|---|
| H1 «Мажезик (MAJEZIK)», вещество | перевод препарата (`MedicineGroupTranslation`: название кириллицей, действующее вещество) |
| «Отпускается по рецепту» | турецкий тип рецепта форм (`Beyaz Reçete` и т. п., не `Reçetesiz`) |
| «Хранение и перевозка при 2–8 °C» | условия хранения форм (`needs_cold_chain`, тот же код, что в SEO карточек) |
| Формы и дозировки с ценами, «цена от» | `/api/catalog/medicines/products?drug_group=<slug>` |
| «От чего помогает», «Как применять — кратко» | перевод препарата, кратко по инструкциям производителей, без доз |
| Источник и дата обновления | «инструкции производителей, зарегистрированные в Турции (TİTCK)», `updated_at` препарата |
| Дисклеймер | «сайт не продаёт лекарства», цены рекомендованные, «по назначению врача» |
| «Читайте также» | три статьи блога |

Title и description строит шаблон (`pages/drugs/[slug].tsx`), если поля перевода пусты:
«Мажезик (MAJEZIK) — флурбипрофен: формы, цена, инструкция»; длинное вещество не помещается —
«…: формы, цена, инструкция» без него. JSON-LD — только
`BreadcrumbList`: `Drug` без `Offer` и рейтинга Google считает ошибкой товара (с 25.10.2026 не выводится). Страницы — в sitemap-секции `drugs` (`/sitemaps/drugs.xml`).

### Какие формы входят

Модель `MedicineGroup`: форма входит, если название медикамента начинается с бренда (или одного из
начал через запятую в «Начала названий»), а за ним пробел, запятая или скобка. AI-название тоже
начинается с бренда латиницей, поэтому правило работает до и после обработки. MAJEZIK не цепляет
MAJEZIKPLUS. Препарат без форм на витрине отдаёт 404 и в sitemap не попадает.

**Не попадают никогда** — формы с отметкой «ввоз ограничен» (TD-024): непустое
`MedicineProduct.import_restricted_countries`. Отметку ставит справочник контролируемых веществ
(`apps/catalog/controlled_substances.py`, [CONTROLLED_SUBSTANCES.md](CONTROLLED_SUBSTANCES.md)) — кодеин,
псевдоэфедрин, эфедрин, прегабалин, фентанил, трамадол и др. по спискам РФ, Казахстана и Узбекистана.
С таких карточек ссылки на страницу препарата нет (отметка читается из базы: в ответе карточки вещество
уже переведено, а отметка считается по исходному турецкому). После релиза TD-024 отметки проставляет
команда `refresh_import_restrictions` — до её запуска поле пустое у всех лекарств.

### Как править

Админка → «Каталог → Категории и справочники → Препараты (страницы брендов)»: бренд латиницей, slug,
начала названий, «Активен», порядок; в переводах — название, вещество, «от чего помогает»,
«как применять», при желании свои H1/title/description и SEO-текст внизу. Тексты пишутся кратко,
без доз, без «без рецепта» и обещаний результата; их проверяет тест
`apps/catalog/tests/test_medicine_groups.py`. Новый препарат — запись в админке (страница и sitemap
появятся сами) или миграция по образцу 0225.

## 6. Микроразметка: что есть

| Страница | JSON-LD |
|---|---|
| Карточка товара | `Product` + `Offer` (цена, наличие, `hasMerchantReturnPolicy`), `aggregateRating` при отзывах; `BreadcrumbList` — было |
| Карточка лекарства | `Drug` **без** `Offer` + `BreadcrumbList` — было, оставлено |
| Категории, подборки, бренды | `BreadcrumbList` — было |
| «Как заказать» | `FAQPage` + `BreadcrumbList` — было |
| Страница препарата | `Drug` (без `Offer`) + `BreadcrumbList` — новое |
| Статьи блога | `Article` + `FAQPage` + `BreadcrumbList` — новое; список статей — `BreadcrumbList` |
| `/delivery` | `FAQPage` (вопросы о ввозе) — новое |

`Offer` на лекарствах не добавлен сознательно: сайт лекарства не продаёт (дисклеймер на карточке,
заявка менеджеру), цена — рекомендованная розничная из списков TİTCK; `Offer` противоречил бы
содержимому страницы (YMYL). Так решено в PR #48 (`canPublishSchemaOffer`). Если владелец захочет
сниппет с ценой — это отдельное решение.

```bash
curl -s https://mudaroba.com/api/catalog/medicines/products?search=levotiron%2075 | grep -o '"slug":"endocrinology-diabetes"'
```
