# Страница «Как заказать» (`/how-to-order-medicines`)

Посадочная страница для лидов по медикаментам: лекарства из Турции и Европы и
стоматологические препараты для клиник. Сайт лекарства **не продаёт** — в текстах
только «консультация / заявка / подбор / расчёт / доставка».

## Где что лежит

| Что | Файл |
|---|---|
| Роутинг, мета, gSSP (контакты футера + баннеры параллельно) | `frontend/src/pages/how-to-order-medicines.tsx` |
| Разделы страницы и вопросы FAQ (`getHowToOrderFaqs`) | `frontend/src/components/HowToOrderGuide.tsx` |
| JSON-LD `FAQPage` + `BreadcrumbList` | `frontend/src/lib/howToOrder.js` (тест `howToOrder.test.mjs`) |
| Тексты ru/en | ключи `hto_*` в `public/locales/{ru,en}/common.json` |
| Форма заявки (`#sourcing`) | `SourcingRequestForm` с `placement="how_to_order"` и своим заголовком |
| Кнопка «Как заказать» на карточке лекарства | `pages/product/[[...slug]].tsx` (ключи `medicine_how_to_order_button`, `_hint`) |

URL оставлен прежним — редирект не нужен, индексация не теряется. В секционном
sitemap (`sitemaps/[section].tsx`, секция static) приоритет страницы 0.8.

У карточек медикаментов блок «Безопасность и сервис» (с пунктом «Безопасность
платежей») скрыт: оплаты на сайте нет. У остальных категорий блок остаётся.

## Структура и SEO

- H1 «Как заказать лекарства из Турции и Европы»; H2: 5 шагов заказа, откуда
  препараты, стоматология для клиник (`#dental`), рецептурные/безрецептурные,
  частным лицам и клиникам, сроки, документы, FAQ, контакты; H3 — карточки и вопросы.
- Ключевые запросы ru: «как заказать лекарства из Турции», «заказать лекарства из
  Европы», «доставка лекарств из Турции», «стоматологические препараты для клиник»,
  «препараты для стоматологии из Турции и Европы», «рецептурные препараты из-за рубежа»,
  «подбор лекарств по фото». En: «how to order medicines from Turkey», «medicines from
  Europe delivery», «dental products for clinics», «prescription medicines from abroad».
- FAQ в JSON-LD строится из того же массива, что и видимый блок — ответы совпадают.
- Сроки доставки взяты со страницы `/delivery` (авиа 3–7 дней, наземная 7–14).

## Баннеры

Позиция `Banner.position = how_to_order` («Страница «Как заказать»» в админке
«Маркетинг — Баннеры»). Включение — `is_active`; тексты и кнопки ru/en — в
переводах слайдов, как у главной. Нет активного баннера с медиа — блок не выводится.

Ссылка кнопки — поле `URLField`, поэтому якорь на форму задаётся полным адресом:
`https://mudaroba.com/how-to-order-medicines#sourcing`. Ссылки на свой домен
карусель открывает в текущей языковой версии (на `/en` — `/en/...`, префикс `/ru`
или `/en` в ссылке игнорируется; `lib/bannerLink.js`), чужие домены — как есть.

Требования к картинкам — как у главной: без текста в изображении, объект слева от
центра (~25–50 % ширины), правая половина — размытый фон под миниатюры карусели,
16:9, webp 1672×941 q80.
