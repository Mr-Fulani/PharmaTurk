# Дубли лекарств и БАДов ilacfiyati с разными адресами

Проверено по коду: 2026-11-09. Код — `backend/apps/scrapers/ilacfiyati_duplicates.py`,
проверка парсера — `ScraperIntegrationService._process_single_product`, команда —
`hide_ilacfiyati_duplicates`, тесты — `apps/scrapers/test_ilacfiyati_duplicates.py`.
Близкая тема — две страницы с одним служебным номером `1111111…`:
[ILACFIYATI_TWIN_PAGES.md](ILACFIYATI_TWIN_PAGES.md).

## Откуда копии «…-2»

Товар ilacfiyati у нас определяется адресом страницы (`external_id` = slug адреса).
Один и тот же препарат становился вторым товаром тремя путями:

1. **Источник переименовал страницу.** Старый адрес отдаёт 301 на новый
   (`adeleks-…-6-ampul-2` → `adeleks-…-6-ampul`, `atacand-plus-16-mg-12-5-mg-…` →
   `…-125-mg-…`). Новый адрес приходил из листинга или sitemap, своего товара не находил
   и заводил второй с тем же штрихкодом. Правило близнецов при разной цене страниц
   отправляло пару «на проверку» и тоже создавало товар.
2. **Поиск по адресу через «содержит».** `external_url__contains="/ilaclar/x"` находил
   чужой товар `/ilaclar/x-2` (его адрес начинается так же): обновление новой страницы
   уходило в него как в «вариант» и отбрасывалось, а аналоги привязывались не к той упаковке.
3. **Снятая регистрация.** У источника остаётся страница со старым штрихкодом и
   «İlaç Durumu: Pasif» (без цены, адрес часто «…-2»). В режиме «Только изменения» такие
   новые карточки не заводились, а при обходе категории — заводились товаром
   «нет в наличии».

## Парсер (с 2026-11-09)

- Новая страница лекарства с **настоящим штрихкодом** (не `1111111…`), у которого уже есть
  показанный товар ilacfiyati с тем же названием в источнике (препарат, числа, форма,
  состав — сравнение `ilacfiyati_twins.mismatch_reason`), — это тот же товар: он
  обновляется, его `external_id` и `external_url` переносятся на новый адрес. Копия не
  создаётся. Другое название при том же штрихкоде — как раньше, правило близнецов.
- Новую карточку «Pasif» товаром не заводим ни в каком режиме: журнал «Пропущен без
  изменений: снят у источника (İlaç Durumu: Pasif), новый товар не заводим». Уже
  сохранённый товар снимается с продажи как раньше (`mark_products_gone`).
- Адрес источника сравнивается целиком (`/ilaclar/x` с концом строки, `/`, `?` или `#`),
  а не «содержит».

## Уже заведённые копии — команда по списку пар

Пары собирает человек (отчёт `reports/medicine-duplicates-…`), CSV с колонками
`keep_id` и `hide_id`; необязательная `same_source_page` = `1` — старый адрес источника
скрываемой отдаёт 301 на адрес оставляемой (проверено при сборе списка). Команда
перепроверяет каждую пару по текущей базе и скрывает только полный дубль. **Сомнительно** (не трогается), если:

| Проверка | Причина в выводе |
| --- | --- |
| товар не лекарство и не БАД, не из ilacfiyati, уже скрыт, оставляемая скрыта | «товар не из ilacfiyati», «скрываемая уже не на сайте», «оставляемая скрыта» |
| одна из карточек — заглушка аналога (на сайте не видна) | «… — заглушка аналога» |
| нет турецкого названия источника | «нет турецкого названия источника» |
| названия: другие числа, единицы, слова, числа адреса, состав | как у близнецов |
| лекарство: оба штрихкода есть и разные (и разные служебные номера `1111111…`) | «разные штрихкоды: A / B» |
| производители разные; TEB — служба ввоза, не производитель, а «İbn-i Sina» и «İbn-İ Sina Sağlık …» — одна фирма (слова одной входят в другую) | «разные производители: A / B» |
| у скрываемой цена есть, у оставляемой нет | «у скрываемой есть цена, у оставляемой нет» |
| скрываемая в наличии, оставляемая нет | «оставляемая не в наличии, скрываемая в наличии» |
| лекарство: обе с ценой, цены (или валюта) разные | «разные цены» |
| при `same_source_page` штрихкод, фирма и цена скрываемой устарели и не сравниваются; название, цена/наличие оставляемой — проверяются | |
| скрываемая оставляется в другой паре или повторяется | «скрываемая оставляется в другой паре» |

У БАДа разные штрихкоды и разные цены при полном совпадении названия и упаковки — дубль
(у источника две карточки одного товара, одна с устаревшей ценой): какую оставить, решает
человек в списке пар, команда проверяет только, что оставляемая не хуже по цене и наличию.
Если источник перенёс страницу, оставлять надо карточку с живым адресом: парсер обновляет
товар по адресу, и у оставленной со старым адресом цена перестала бы обновляться.

Проверка 09.11.2026 и списки пар — `reports/ilacfiyati-duplicates-2026-11-09.md`.

«Скрыть» — как у близнецов: `is_active=False` у `Product` и доменной карточки
(`MedicineProduct` / `SupplementProduct`) через `QuerySet.update`, в
`external_data["ilacfiyati_duplicate_of"]` — id оставленного товара, адреса скрытого
(`Product.slug` и slug доменной карточки) — в `ProductSlugHistory` → **301** на
оставленный товар. Ничего не удаляется. Каталог, поиск, sitemap, YML-фид берут только
активные товары. Строки Списков заявки, заявки и избранное остаются; команда печатает,
сколько их у каждого скрываемого.

```bash
manage.py hide_ilacfiyati_duplicates --pairs pairs.csv                          # показ
manage.py hide_ilacfiyati_duplicates --pairs pairs.csv --csv decisions.csv      # показ + CSV
manage.py hide_ilacfiyati_duplicates --pairs pairs.csv --apply --backup /backups/ai-pilot/dups-20261109.json
manage.py hide_ilacfiyati_duplicates --restore /backups/ai-pilot/dups-20261109.json           # показ отката
manage.py hide_ilacfiyati_duplicates --restore /backups/ai-pilot/dups-20261109.json --apply   # откат
```

`--apply` без `--backup` или с уже существующим файлом отказывает. Откат возвращает
`is_active`, прежний `external_data`, удаляет строки `ProductSlugHistory` скрытых адресов
и возвращает те, что были до скрытия.
