# Кнопки «Посмотреть на сайте» и «Источник» в карточке товара (админка)

Дата: 20.11.2026. Код: `backend/apps/catalog/admin_links.py` (`product_view_buttons`),
тег `catalog_admin_links`, шаблон `backend/templates/admin/change_form_object_tools.html`.
Тесты — `apps/catalog/tests/test_admin_product_view_buttons.py`.

На странице редактирования товара любого раздела (общий «Товар», лекарство, БАД, одежда,
обувь, мебель и остальные доменные записи) вверху справа, рядом с «История», стоят кнопки.
Все открываются в новой вкладке.

- **«Посмотреть на сайте»** — карточка на сайте. Адрес — `FRONTEND_SITE_URL` +
  `build_canonical_path` по типу и slug общего товара (так же страницу находит сайт).
  Кнопки нет, если страницы на сайте нет: товар выключен («Активен» снят, в том числе скрытый
  дубль), это служебная запись расцветки (`source_variant_id` / `source_variant_slug`) или
  заглушка аналога лекарства.
- **«Источник: <домен>»** — страница товара у продавца, по кнопке на каждый адрес: ссылка
  товара (`external_url`), затем адреса предложений источников (`ProductSourceOffer`) без
  повторов. У доменной записи берутся источники её общего товара. Несколько адресов одного
  продавца (расцветки) различаются номером: «Источник: flo.com.tr · 2»; полный адрес — во
  всплывающей подсказке. Показываются только адреса http(s).
- Адресов больше пяти (`SOURCE_BUTTONS_LIMIT`) — первые пять и кнопка «Ещё источников: N»,
  она открывает список «Предложения источников» этого товара.
- У товара без источника кнопок источника нет.

Механизм один на всю админку: шаблон блока кнопок переопределён для всех страниц, тег
выводит кнопки только для `Product` и доменных моделей (`AbstractDomainProduct`), на
остальных страницах блок прежний. Новому разделу каталога подключать ничего не нужно.
Админка с собственным шаблоном, который заменяет блок `object-tools` целиком, кнопок не
получит — блок нужно расширять через `{{ block.super }}`.
