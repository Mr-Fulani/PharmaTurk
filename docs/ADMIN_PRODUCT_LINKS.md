# Кнопки «На сайте» и «У продавца» в карточке товара (админка)

Дата: 20.11.2026. Код: `backend/apps/catalog/admin_links.py` (`product_view_buttons`),
тег `catalog_admin_links`, шаблоны `backend/templates/admin/change_form.html` (полоса кнопок)
и `change_form_object_tools.html` (её пункты). Вид кнопок — [ADMIN_HOME_TILES.md](ADMIN_HOME_TILES.md).
Тесты — `apps/catalog/tests/test_admin_product_view_buttons.py`.

На странице редактирования товара любого раздела (общий «Товар», лекарство, БАД, одежда,
обувь, мебель и остальные доменные записи) под заголовком стоит полоса кнопок: «🌐 На сайте»,
«🏪 У продавца: <домен>», «🕘 История». На телефоне кнопки идут в столбик на всю ширину.
Кнопки сайта и продавца открываются в новой вкладке.

- **«На сайте»** — карточка на сайте. Адрес — `FRONTEND_SITE_URL` +
  `build_canonical_path` по типу и slug общего товара (так же страницу находит сайт).
  Кнопки нет, если страницы на сайте нет: товар выключен («Активен» снят, в том числе скрытый
  дубль), это служебная запись расцветки (`source_variant_id` / `source_variant_slug`) или
  заглушка аналога лекарства.
- **«У продавца: <домен>»** — страница товара у продавца: ссылка
  товара (`external_url`), затем адреса предложений источников (`ProductSourceOffer`) без
  повторов. У доменной записи берутся источники её общего товара. Несколько адресов одного
  продавца (расцветки) различаются номером: «У продавца: flo.com.tr · 2»; полный адрес — во
  всплывающей подсказке. Показываются только адреса http(s). Один адрес — обычная кнопка;
  несколько — одна кнопка «У продавца: несколько ссылок», по нажатию под ней раскрывается
  список (`<details>`, без JavaScript).
- Адресов больше пяти (`SOURCE_BUTTONS_LIMIT`) — в списке первые пять и «Ещё источников: N»,
  она открывает список «Предложения источников» этого товара.
- У товара без источника кнопки продавца нет.

Механизм один на всю админку: шаблон блока кнопок переопределён для всех страниц, тег
выводит кнопки только для `Product` и доменных моделей (`AbstractDomainProduct`), на
остальных страницах в полосе только «История». Новому разделу каталога подключать ничего не нужно.
Админка с собственным шаблоном, который заменяет блок `object-tools` целиком, кнопок не
получит — блок нужно расширять через `{{ block.super }}`.
