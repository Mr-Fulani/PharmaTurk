# YML-фид для ВК Маркета и Яндекса

Обновлено 2026-10-27.

## Как работает

- Ссылка: `https://mudaroba.com/api/catalog/export/yml/catalog.yml` — полный каталог;
  `?category=<slug>` — категория с подкатегориями. Ссылки всех разделов и время
  их сборки — в админке «Маппинги категорий ВК» (`/admin/catalog/vkcategorymapping/`).
- **Корневые категории и полный каталог** собирает задача Celery
  `catalog.generate_yml_feeds` каждые 6 часов (00:35, 06:35, 12:35, 18:35 МСК) в файлы
  `feeds/yml/` хранилища (на проде — R2). Какой файл актуален, хранит таблица
  `YMLFeedSnapshot` (раздел, время сборки, число офферов, размер). Эндпоинт отдаёт
  готовый файл потоком, с `ETag`/`Last-Modified` (повторный запрос с `If-None-Match` → 304).
  Лимит — 30 запросов в минуту с IP.
- **Подкатегории** (`?category=<slug подкатегории>`) собираются на лету потоком,
  лимит 2 запроса в минуту с IP.
- Если готового файла ещё нет (сразу после первого деплоя), эндпоинт отвечает 503
  с `Retry-After: 600` и сам ставит сборку (не чаще раза в 10 минут). Пересобрать
  вручную — кнопка «Пересобрать фиды сейчас» в той же админке.
- Сборка: товары читаются пачками по 500, доменные записи (обувь, одежда…), фото,
  активные варианты и атрибуты подгружаются одним запросом на тип товара в пачке —
  число запросов не растёт с числом товаров. XML пишется по одному `<offer>`,
  память не растёт с размером каталога. Код — `backend/apps/catalog/services/yml_feed.py`.
- Не попадают в фид: выключенные товары и лекарства с ограничением ввоза (TD-024).
- Цена варианта переводится в рубли с наценкой, как на сайте (раньше уходила
  цена в лирах с пометкой RUB).
- Файлы `feeds/` защищены от `cleanup_orphaned_media`; старый файл раздела удаляет
  сама сборка после переключения на новый.

## Фото в ВК

Кнопка «Синхронизировать» в таблице разделов ставит фоновую задачу
`catalog.sync_vk_photos` (команда `sync_vk_photos`, категория с подкатегориями).
Итог приходит администратору в Telegram. Нужен `VK_USER_TOKEN` в `.env` (на проде
на 27.10 не задан — кнопка покажет ошибку и ничего не запустит). Синхронизация
меняет публичную витрину ВК — только с согласия владельца.

## Ограничения ВК (справка vk.com/faq21697)

- файл YML до **8 МБ** и до **15 000 товаров**;
- полный каталог и, вероятно, раздел «Медицина» больше этих лимитов — в ВК
  подключать фиды отдельных разделов (размер и число офферов видно в админке);
- по правилам сообществ ВК лекарства через «Товары» продавать нельзя, БАДы —
  с ограничениями; раздел «Медицина» в ВК не подключать. Яндекс Маркет лекарства
  тоже не принимает.

## Категории ВК (`<market_category>`) — ждёт решения владельца

Как ВК использует `<market_category>` при импорте YML, в открытой документации не
описано; по сторонним источникам категорию ВК задают числовым ID или выбирают при
импорте, а `<categories>` фида превращаются в подборки сообщества. Сейчас в базе
4 записи (с апреля 2026), для остальных типов — запасной словарь в коде, названия в
нём не совпадают с деревом ВК:

| Тип | Сейчас | Предложение |
|---|---|---|
| Мебель | «Дом и дача Мебель» (нет « > ») | «Дом и дача > Мебель» |
| Обувь | «Гардероб > Мужчинам > Обувь» (и женская) | мужская «Гардероб > Мужчинам > Обувь», женская «Гардероб > Женщинам > Обувь» |
| Головные уборы | «Гардероб > Мужчинам > Аксессуары» | по полу: «Гардероб > Мужчинам / Женщинам > Аксессуары» |
| Одежда, бельё, исламская одежда | словарь кода («Одежда, обувь и аксессуары > …») | по полу: «Гардероб > Мужчинам / Женщинам > …» |
| БАДы | «Витамины, БАДы и пищевые добавки» | оставить (название подтверждено, ID 20098) |
| Парфюмерия, благовония | словарь кода | «Парфюмерия» (20093), «Ароматерапия» (20094) |
| Посуда / Книги / Мебель / Автозапчасти | словарь кода | «Посуда и товары для кухни» (20020), «Книги и журналы» (20029), «Мебель» (20026), «Запчасти» (20122) |
| Медтехника | словарь кода | «Медицинские изделия и расходные материалы» (20178) — если правила ВК разрешат |
| Лекарства | словарь кода | в ВК не выгружать |

Подтверждены только названия второго уровня с ID (из вывода `market.getCategories`
стороннего клиента); третий уровень («Обувь», «Аксессуары») и названия корней
(«Гардероб», «Дом и дача») взяты из записей владельца. Разделение «Мужчинам /
Женщинам» требует доработки кода (сейчас маппинг по типу товара, без пола).

Порядок: 1) владелец открывает редактор товара ВК и сверяет названия либо делает
пробный импорт 1–2 товаров; 2) если ВК категорию из фида учитывает — правим записи
в админке и, при согласии, добавляем пол в маппинг; если нет — категории
выбираются в ВК при импорте, а маппинг нужен только для Яндекса.

## После деплоя

1. Миграция `catalog.0227_yml_feed_snapshot`; пересоздать `celeryworker` и
   `celerybeat` (код задач запечён в образ).
2. Админка → «Маппинги категорий ВК» → «Пересобрать фиды сейчас»; через несколько
   минут в таблице появятся время сборки, число офферов и размер.
3. Смоук: `curl -sI 'https://mudaroba.com/api/catalog/export/yml/catalog.yml?category=headwear'`
   → 200, `ETag`, быстро; то же для `furniture` и `medicines`; первые `<url>` в файле
   начинаются с `https://mudaroba.com/product/` (иначе проверить `FRONTEND_SITE_URL`).
