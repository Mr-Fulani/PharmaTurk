# Память переводов: БАДы (05.11.2026)

Решение владельца 05.11.2026: **сначала полностью БАДы**, одежда, обувь и остальное — следующий этап, работ по
ним пока нет.

## Коротко

- **Лекарства** уже переводятся из памяти: новое лекарство почти целиком собирается из готовых проверенных
  абзацев, модель переводит только новые фразы.
- **БАДы** до этой работы: модель для каждого товара заново пересказывала одни и те же предупреждения и состав.
- **Сделано:** память для БАДов (PR #313). Состав, вспомогательные вещества, способ применения,
  предупреждения и хранение переводятся по частям один раз и дальше берутся из памяти. На карточке они идут
  отдельными абзацами «Состав: …», «Способ применения: …» и т. д.
- **Два пилота по 50 товаров** прошли на сервере в отдельном контейнере, база прода только на чтение,
  на прод ничего не записано. После каждого ошибки исправлены кодом.
- **Деньги — не главная выгода.** 50 карточек: $0,023 без памяти, $0,032 с памятью (в том числе разовый
  перевод частей). Польза: один проверенный перевод на всех карточках, полный состав для покупателя, модель
  меньше выдумывает, исправление в одном месте действует для всех товаров.
- **Важно:** на проде ни у одного из 7 677 БАДов пока нет разделов источника («Ürün Bilgisi», «Ürün
  İçeriği»). Полного прохода БАДов парсером после починки сайта источника не было. Без него памяти нечего
  подставлять на сайте.

## 2. Что повторяется у БАДов

Замер на 372 карточках сайта источника (тем же парсером, что на проде): разделы есть у 33 %, в среднем 7–8
частей на карточку. Абзацы целиком почти не повторяются, повторяются **компоненты состава** и **типовые фразы
этикетки** («Tavsiye edilen günlük porsiyonu aşmayın» — «Не превышайте рекомендуемую суточную порцию»).
Поэтому единица памяти — один компонент или одно предложение. Доля повторов растёт с числом товаров:
в пилоте 2 после памяти всего одного пилота 65 частей из 319 (20 %) уже взяты из неё без модели.

## 3. Пилоты

Карточки — с сайта источника (на проде разделов пока нет), обработка — кодом PR на образе прода, модель
Claude Haiku 5.5, база прода только на чтение. Для каждой карточки сделано «было» (прежняя обработка) и
«стало» (с памятью).

### Что нашла ручная сверка и как исправлено кодом

| ошибка | пример | исправление |
|---|---|---|
| растения состава | «Rezene» (фенхель) → «укроп», «Mine Çiçeği» (вербена) → «мята», «Roybos» (ройбос) → «розмарин», «Dul Avrat Otu» (лопух) — транслитерация | подсказки словаря переводчику + проверка: вещество словаря переведено иначе — перевод не принимается; в словарь добавлены вербена, ройбос, галега, витекс, лопух, дымянка. На 200 переводах пилота 1 проверка отметила ровно 8 ошибочных, ложных нет |
| английский вместо русского | «Приём docosahexaenoic acid»; один запрос из 10 компонентов целиком по-английски | проверка «английское слово, которого нет в источнике» + один повтор |
| варианты подсказки в переводе | «Kapsül kabuğu» → «кора / кожура капсулы» | в подсказки идут только вещества |
| таблица доз как состав | «Vitaminler / Vitamin A / 640 μg RE» | таблица под подписью состава не берётся |
| не те фразы в блоках | «не содержит аллергенов», «подходит веганам» в предупреждениях и хранении; реклама в способе применения; срок годности и номер партии | отбрасываются; предупреждение под подписью хранения уходит в предупреждения |
| список из одних вспомогательных веществ под «Состав» | SOLGAR: действующее вещество в таблице доз | подпись «Вспомогательные вещества» |
| грамматика | «Один таблетка», «БАД не заменяют» | правило в промпте: числа цифрами, «БАДы не заменяют полноценное питание» |

Осталось редкое: названия солей («Trimagnezyum sitrat» → «Трижды магния цитрат» вместо «тримагния цитрат»).
Такую запись достаточно исправить один раз в админке «Память переводов AI» — исправление сразу действует для
всех товаров с этим компонентом.

### Пример «было/стало» (пилот 2, ответ модели, сокращено)

**SUDA VITAMIN MENS FORMULA PROXINE, 60 капсул**

Было:
> Suda Vitamin — растительный комплекс для взрослых мужчин в капсулах, 60 штук. В состав входят экстракт сабаля
> (Serenoa repens), экстракт семян тыквы, экстракт Pygeum africana, экстракт крапивы и экстракт имбиря, а также
> витамин E, цинк, селен и ликопин. Принимать по 2 капсулы в день после еды. …

Стало:
> Suda Vitamin Mens Formula Proxine — капсулы для мужчин, содержащие экстракты карликовой пальмы, тыквенных семян,
> пигеума, крапивы и имбиря, а также витамин E, цинк, селен и ликопин. …
>
> Состав: мальтодекстрин, экстракт карликовой пальмы (сереноа) (Serenoa repens), растительная капсула
> (гидроксипропилметилцеллюлоза), экстракт косточек тыквы (Cucurbita sp.), экстракт Pygeum africana, наполнитель
> (кальция фосфаты), экстракт крапивы (Urtica sp.), DL-альфа-токоферилацетат, экстракт имбиря (Zingiber officinale),
> цинка сульфат, антислёживающие агенты (магниевые соли жирных кислот, диоксид кремния), красители (оксид железа
> красный), ликопин, селенит натрия.
>
> Способ применения: Взрослым мужчинам рекомендуется принимать по две растительные капсулы после еды в день.
>
> Предупреждения: Не превышайте рекомендуемую суточную порцию. Произведено на предприятиях, перерабатывающих молоко,
> сою, яйца, злаки, содержащие глютен. Возможно попадание следовых количеств.
>
> Хранение: Хранить при комнатной температуре, в прохладном и сухом месте. Не подвергать воздействию прямых
> солнечных лучей.

**SOLGAR VITAMIN B2 (RIBOFLAVIN), 100 капсул** — «стало» добавило:
> Вспомогательные вещества: капсула (гидроксипропилметилцеллюлоза), антислёживающие агенты (магниевые соли жирных
