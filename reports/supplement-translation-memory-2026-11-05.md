# Память переводов: БАДы (05.11.2026)

Решение владельца 05.11.2026: **сначала полностью БАДы**, одежда, обувь и остальное — следующий этап, работ по
ним пока нет.

## Коротко

- **Лекарства** уже переводятся из памяти: новое лекарство почти целиком собирается из готовых проверенных
  абзацев, модель переводит только новые фразы.
- **БАДы** до этой работы: модель для каждого товара заново пересказывала одни и те же предупреждения и состав.
- **Сделано:** память для БАДов (PR #313). Состав, вспомогательные вещества, способ применения,
  предупреждения и хранение переводятся по частям один раз и дальше берутся из памяти. На карточке они идут
  отдельными абзацами «Состав: …», «Способ применения: …» и т. д.
- **Четыре пилота по 50 товаров** прошли на сервере в отдельном контейнере, база прода только на чтение,
  на прод ничего не записано. После каждого ошибки исправлены кодом.
- **Деньги — не главная выгода.** 50 карточек: $0,023 без памяти, $0,032 с памятью (в том числе разовый
  перевод частей). Польза: один проверенный перевод на всех карточках, полный состав для покупателя, модель
  меньше выдумывает, исправление в одном месте действует для всех товаров.
- **Важно:** на проде ни у одного из 7 677 БАДов пока нет разделов источника («Ürün Bilgisi», «Ürün
  İçeriği»). Полного прохода БАДов парсером после починки сайта источника не было. Без него памяти нечего
  подставлять на сайте.

## 2. Что повторяется у БАДов

Замер на 372 карточках сайта источника (тем же парсером, что на проде): разделы есть у 33 %, в среднем 7–8
частей на карточку. Абзацы целиком почти не повторяются, повторяются **компоненты состава** и **типовые фразы
этикетки** («Tavsiye edilen günlük porsiyonu aşmayın» — «Не превышайте рекомендуемую суточную порцию»).
Поэтому единица памяти — один компонент или одно предложение. Доля повторов растёт с числом товаров:
в пилоте 2 после памяти всего одного пилота 65 частей из 319 (20 %) уже взяты из неё без модели.

### Ревью координатора и пилот 4

Координатор нашёл в PR 8 проблем, все исправлены, на каждую есть тест на реальном примере. Главные:
- **Предупреждения терялись молча.** Фильтр «обещаний лечения» выбрасывал из блоков настоящие предупреждения
  («Лицам с хроническими заболеваниями… не применять без консультации врача») и «экстракт лечебной ромашки» из
  состава. Теперь блоки так не фильтруются; если в переводе оказалось обещание пользы, блок не показывается целиком —
  лучше без блока, чем неполный.
- **Перевороты смысла.** Новые проверки не принимают перевод, где запрет стал разрешением («не применять» →
  «можно применять»), перепутаны «натощак» и «после еды», «младше» и «старше»; короткие компоненты («Желатин»,
  «Вода») переводятся по одному, чтобы модель не могла их переставить.
- **Связь с модерацией.** Переводы карточки, которую модератор отклонил, больше не используются для других товаров.
- Мелкое: противопоказание «Aşağıdaki durumlarda kullanmayınız: …» больше не теряется, фраза, перенесённая после
  запятой, склеивается, а оборванная — не показывается; кальций и витамин E не считаются вспомогательными веществами.

Пилот 4 (47 новых карточек — БАДов с разделами в выборке больше не осталось) нашёл заявления о пользе в «Способе
применения» («способствует снижению усталости»): их отсекал как раз убранный фильтр. Теперь они не берутся по
турецкому исходнику, а перевод проверяется ещё раз. Также модель однажды скопировала подсказку словаря («прополис |
propolis») — перевод не принимается. В словарь добавлены чайное дерево, клюква крупноплодная, мембрана яичной скорлупы.

Проверка кодом на всех 609 переводах трёх пилотов отмечает ровно те 7 ошибок пилота 3, что нашла ручная сверка;
верные переводы она не трогает. Доля частей из памяти в пилоте 3 ниже, чем во 2-м (17 % против 20 %): в выборку
попали товары других производителей (детская смесь Aptamil, спреи), их составы ещё не встречались.
